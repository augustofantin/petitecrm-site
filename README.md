# PetiteCRM — páginas públicas

Páginas estáticas do PetiteCRM servidas pelo GitHub Pages
(https://augustofantin.github.io/petitecrm-site/).

- `email-confirmado.html`: destino do link de confirmação de cadastro
  (Site URL / Redirect URL do Supabase Auth).
- `index.html`: página inicial (o que é o PetiteCRM, recursos e planos "sob consulta").
- `termos.html`: termos de uso.
- `privacidade.html`: política de privacidade (LGPD).
- `style.css`: estilo compartilhado das páginas acima.

Os textos de termos e privacidade são um rascunho e não substituem revisão jurídica. O canal
público de contato ainda precisa ser preenchido nas três páginas (procure "canal público").
- `redefinir-senha.html`: destino do link de "Esqueci minha senha" do app (define a nova senha
  pelo Supabase Auth; a URL precisa estar nos Redirect URLs do Supabase).
